# 产品与架构

## 产品定位

「模拟输入」是一个 macOS 常驻工具,核心能力是**在别的 App 里代替你操作**(模拟点击/输入/按键)、
**切换输入法**、**录制并回放操作序列**,以及一个可选的增强能力:**Safari 复制修复**
(让被网页字体混淆过的文字,复制出来是你看到的那句话)。

## 进程模型

```
Electron 主进程 (main.js)
├── 窗口管理         window:minimize/maximize/quit
├── 设置持久化       settings.json (userData 目录)
├── 功能模块注册表   src/features/index.js  ← 新增功能只改这里
│   └── safari-repair/  (src/features/safari-repair/)
│        ├── index.js        模块入口(init/registerIpc/dispose)
│        ├── coordinator.js  调度:轮询标签页、注入守卫、下发映射
│        ├── bridge.js       Apple Events 桥(执行页面 JS、注入、读状态)
│        ├── engine.js       字形还原(解析字体 → 与参考库比对 → 出映射)
│        ├── fast-matcher.js 快速最近邻(精确哈希快路径)
│        └── paths.js        路径解析(统一算 vendor/ 的位置)
├── 原生模块         mac-coregraphics/(仅 macOS,必须 asarUnpack)
└── 激活授权         activation:*  (机器指纹 + 授权码)

渲染进程 (src/,React + Vite)
├── 激活 / 试用
├── 文件管理(录制文件)
├── 模拟输入控制(点击/文本/按键/录制回放)
├── 输入源设置
└── 功能开关区(按 features.list() 渲染,新功能自动出现)
```

## 目录结构

| 路径 | 内容 | 打包 |
| --- | --- | --- |
| `src/` | 前端(React)+ 功能模块 | ✅ dist/ 与 src/features/ |
| `main.js` `preload.js` | 主进程 / 预加载 | ✅ |
| `mac-coregraphics/` | 原生模块(CoreGraphics) | ✅(必须解包) |
| `vendor/` | 运行时依赖(参考库、字体解析器、注入脚本) | ✅ |
| `backend/` `electron/` `build/` | 后端脚本、构建配置 | ❌ |
| `docs/` | 文档系统 | ❌ |
| `tools/` | 开发脚本(lab 实验 / verify 校验) | ❌ |
| `release/` | 构建产物 | — |

## 功能的加法

新增一个功能 = 三步:

1. 建 `src/features/<功能名>/`,导出 `{ id, title, init(ctx), registerIpc(ipcMain, { settings }) }`
2. 在 `src/features/index.js` 的 `FEATURES` 里加一行
3. 前端从 `cnc.getFeatures()` 拿清单渲染开关(见 [新功能开发指南](../03-开发/新功能开发指南.md))

功能自己的设置存在 `settings.json` 的 `features.<功能名>.<键>`,互不冲突。
