# ADR-0015:Electron 版「默认执行」没功能 —— 根因是缺「辅助功能」权限,而失败是**静默**的

- 状态:已定(Electron / macOS 已修)
- 日期:2026-10-24
- 相关:ADR-0013(快捷键 ⌃S/⌃D + latch)、ADR-0014(打包白名单漏文件)、
  ADR-0003(原生模块必须 asarUnpack)
- 交叉:Tauri 仓库 **ADR-0025** 同名决策

## 背景

用户装上修复后的 Electron 版,反馈:

> 「现版本的 electron 版本根本就不能用,**至少默认执行是没有功能的**」

「默认执行」= 回放选中的录制文件(逐条发合成点击 + 键入文本)。

---

## 一、根因:缺「辅助功能」权限 ⇒ 合成事件被**静默丢弃**

发合成点击/按键走 `CGEventPost`。**没有 macOS 的「辅助功能」权限时,
系统会静默丢弃这些事件**:命令返回成功,屏幕上却什么都没发生。

于是 Electron 线之前的状态是:

```
用户点「默认执行」
      ↓
playClicks → mouseClick(x, y) → CGEventPost(...)
      ↓
❌ 没有权限 ⇒ 事件被系统丢弃 ⇒ 屏幕上什么都没发生
      ↓
但命令**返回成功** ⇒ executed 照加 1
      ↓
界面显示「开始执行」 ⇒ 用户看到"执行了",实际一点反应都没有
```

⇒ 这就是「**默认执行没有功能**」。

---

## 二、为什么 Tauri 线能用、Electron 线不能

Tauri 线早就有四道防线,Electron 线**一道都没有**:

| 防线 | Tauri | Electron(修之前) |
| --- | --- | --- |
| 查授权状态 | `accessibility_trusted()` → `AXIsProcessTrusted()` | ❌ 完全没有 |
| 发事件前的**闸门** | `require_accessibility()` → 没权限**报错** | ❌ 没有 ⇒ 静默丢弃 |
| 界面显示状态 | `getNativeStatus` 带 `accessibilityTrusted` + 第 4 页一个小问号 | ❌ 两样都没有 |
| 签名 | **Apple Development**(真证书,`TeamIdentifier=769LN7AY28`) | ❌ **ad-hoc**(`TeamIdentifier=not set`) |

### 签名这一条是**前提条件**

`ad-hoc` 签名没有稳定的代码身份 ⇒ 用户在「系统设置 → 隐私与安全性 → 辅助功能」里
勾选这个 App 之后,**每次重新构建、重新签名,身份都会变** ⇒ 授权留不住。

⇒ 没有真签名,后面三道防线修好了也没用:用户仍然授权不了。

---

## 三、修法

### ① 原生层(`mac-coregraphics/src/main.mm`)

- 新增 `accessibilityTrusted()` → `AXIsProcessTrusted()`;
- 新增 `requestAccessibility()` → `AXIsProcessTrustedWithOptions(prompt)`
  (让系统弹授权框,用户在弹窗里点「允许」);
- **`mouseClick` / `sendText` / `sendKey` 三个函数发事件前加闸门**:
  没权限就**抛错**,错误文案带人话指引:
  > `模拟点击需要「辅助功能」权限:系统设置 → 隐私与安全性 → 辅助功能 → 勾选本应用(改完要重开软件)`

  ⇒ **绝不假装成功** —— 假装成功就是"计数照加、屏幕上什么都没发生"。
- 链接 `-framework ApplicationServices`(Carbon 里没有 `AXIsProcessTrusted`)。

### ② 主进程(`main.js` / `preload.js`)

- `native:getStatus` 带上 `accessibilityTrusted`(与 Tauri 同字段名);
- 新增 `native:requestAccessibility`(弹系统授权框)与
  `window:openAccessibilitySettings`(跳到系统设置那一页);
- **回放/键入的入口前置检查**:没权限就直接返回
  `{status:'error', message:'没有「辅助功能」权限…'}` ——
  界面本来就会显示 `result.message`,**不用为它另开一条通路**;
- **计数口径与 Tauri 收拢**(此前两边不一致,一直挂着待拍板):
  发不出去 ⇒ **不计入 executed**、记**第一个** error、**继续往下走**。

### ③ 界面层(`src/panels/KeyboardPanel.jsx` + `src/App.jsx`)

- 键盘面板的**「辅助功能」小问号**与 Tauri **逐字一致**
  (红=还不能用、绿=可以用、灰=状态未知;点一下跳系统设置);
- `App.jsx` 传三个 props:`showAccessibilityBadge` / `accessibilityTrusted` /
  `onOpenAccessibilitySettings`。

> ⚠️ 这一条是 **ADR-0013(界面层逐字照搬)**的修复:之前 Tauri 有、Electron 没有,
> 属于界面层漂移 —— 漂移的方向正好是「用户看不到自己缺权限」。

### ④ 签名(`electron/after-pack.cjs`)

- **优先用钥匙串里有效的代码签名身份**(本机是 `Apple Development: 8618291894921`);
- 真证书签不了才退回 ad-hoc(并打日志);
- CI 上没有证书 ⇒ 仍是 ad-hoc(分发场景的限制,见 `项目记忆.md`)。

## 四、验证

| 项 | 结果 |
| --- | --- |
| 原生层冒烟(无权限进程) | `mouseClick` / `sendText` **抛错**,带人话指引(不再假装成功) |
| `accessibilityTrusted` | 无权限进程返回 `false` ✓ |
| 回归 | UI/快捷键/回放 **10/10**(`verify-panel-transition` / `verify-recording-ui` / `verify-shortcut-latch` / `verify-playback-guard`) |
| 打包自检 | 全绿(含「包内所有相对 require 都能解析」) |

## 五、诚实的边界

**光把代码修好,事件还发不出去 —— 最后一步必须用户手动点。**

合成事件要真正发出去,用户得在
「系统设置 → 隐私与安全性 → 辅助功能」里勾选**这个** App
(它的 bundle ID 是 `com.gojocloud.campus-network-connector`,
和 Tauri 版的 `…connector.tauri` **不是同一个** ⇒ 不共用那份授权),
然后**重开软件**。

这一步系统不提供程序化的授权接口,只能用户自己点。
App 现在的职责是:**把这件事告诉你**(小问号 + 一键跳设置页),
而不是让你对着一个毫无反应的软件猜。

**CI 产出的包仍然是 ad-hoc 签名的**(CI 机器上没有证书)⇒
从 GitHub Release 下载的包,授权照样留不住。这是**分发侧**的限制,
要彻底解决需要 Developer ID 证书(付费团队),已记在 `项目记忆.md`。

## 六、教训

**「命令返回成功」不等于「事情做成了」。**
合成输入 API 在缺权限时**返回成功但什么都不做** ——
Tauri 线早就为它加过闸门(`require_accessibility`),
Electron 线没抄这道闸 ⇒ 同一个坑,两条线各踩一次。

**失败必须可见。** 没有闸门 + 没有状态显示 = 静默失败 =
用户只能说「没有功能」,而我们连他为什么没功能都不知道。

**签名不是形式。** `ad-hoc` 签名让「用户授权」这件基础事**做不稳** ——
每次重新构建都重新开始。权限类功能的前提是**稳定的代码身份**。
