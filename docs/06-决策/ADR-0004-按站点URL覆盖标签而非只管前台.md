# ADR-0004:按站点 URL 覆盖目标标签,而不是只管前台标签

- 状态:已定
- 日期:2026-10-21

## 背景

初版调度只处理 `front tab of front window`(前台标签)。问题:

- 用户换题、换标签后,目标页不是前台 → **完全没人管** → 复制完全不修复
- 观察到的现象:`pending` 一直是 3(守卫上报了没人消费)、`mappings` 一直是空

## 决定

1. 协调器每 2 轮做一次 `listTabs()`(一次 Apple Event 拿全所有窗口的所有标签),
   把 URL 命中**目标站点清单**的标签全部纳入调度
2. 目标站点清单写在该功能模块内(`src/features/safari-repair/index.js` 的 `SITE_FILTER`),
   默认 `['chaoxing.com']` —— 本产品只服务这一个站
3. 目标站点清单可配置(在 `main.js` 的 `SAFARI_REPAIR_SITES`),加别的域名只改一行
4. 另外保留"看住过的标签"(URL 持久化到设置),作为兜底

## 代价

- 每 2 轮多一次 `listTabs()`(一个 Apple Event)+ 每个命中标签一次轮询 → CPU 2.7~4.2%
- 标签序号会变 → **必须按 URL 定位**,不能用固定序号(踩过一次)

## 验证

目标页不在前台(前台是 aistudio)时,复制仍被修复:119 字符、零密文残留 ✅
