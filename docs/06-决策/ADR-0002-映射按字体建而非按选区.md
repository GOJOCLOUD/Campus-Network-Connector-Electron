# ADR-0002:映射按字体建,而不是按选区建

- 状态:已定
- 日期:2026-10-21

## 背景

引擎算出的对照表是"码位 → 可见字"。问题:**表里要放多少个码位?**

第一版按选区建:只还原"采集那一刻选区里出现过的字"。

## 出问题的地方

用户反馈:5 道题只还原了第 1 题。诊断:

```
作用域 400 | font-cxsecret | 字符数=671 元素=58   ← 整页 5 题都在这个作用域
映射只有 7 个 (垕垖垔垘垙垗)                        ← 只有第 1 题的密文字
pending 102 字 font-cxsecret 字体=data:13824         ← 采集到了,但没被消费
```

按选区建映射时,用户后来扩大选区,新出现的密文字不在映射里 → 复制出来是密文。

## 决定

**映射按字体建**:字体里每个码位的对照关系一次算完,整份下发。任意选区都覆盖得到。

附带好处:映射与选区解耦后,**预热**成为可能(装好就建好映射,不用等用户选中)。

## 影响

- 引擎的输出从"这次选区的映射"变成"这个字体的映射"
- 页面守卫按字符所属作用域查表(作用域 key 含字体内容指纹,换字体即换作用域)
