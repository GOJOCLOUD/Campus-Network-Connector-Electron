# 需求与验收标准

每条需求都带**可执行的验收方式**;没有验收方式的需求不写进来。

## R1 模拟输入(原生模块)

在任意 App 里代替用户操作:鼠标点击、发送文本、发送按键。

- [ ] 点击/文本/按键三类操作都能生效
- [ ] 录制 → 回放流程能跑通
- [ ] **原生模块不可用时,界面顶部出现红色告警条**,而不是按钮静默失灵
- [ ] 安装包里原生模块位于 `app.asar.unpacked/`(装完即可用)

验收:`node tools/verify/verify-package.cjs` 全绿 + 界面无告警条。

## R2 输入源切换

读取/切换 macOS 输入源(ASCII / 拼音)。

- [ ] 读当前输入源、切换、设为当前,均正常
- [ ] 配置(pinyin_sources / ascii_id / 快捷键)能保存并生效

## R3 Safari 复制修复

在 Safari 里,被网页字体混淆过的文字,复制出来 == 屏幕上看到的那句话。

- [ ] 只覆盖目标站点(默认 `chaoxing.com`),其它站点不受影响
- [ ] 目标页**不在前台**时也能修复(不依赖前台标签)
- [ ] 换题、换一套加密字体后仍然生效(字体是运行时读现场)
- [ ] 复制富文本时,纯文本那一路被正确替换
- [ ] 识别不出来时**不替换**(宁可留怪字也不写错字)
- [ ] App 窗口关掉后功能仍在后台运行(Dock 图标还在)
- [ ] 目标页 iframe 重建后守卫能自愈

验收:`node tools/verify/verify-app-e2e.cjs` → 剪贴板内容为可见文字、零密文残留。

## R4 激活授权

机器指纹 + 授权码 + 试用,状态持久化。

- [ ] 未激活走激活流程,已激活显示"已激活"
- [ ] 授权状态重启后保留
- [ ] 旧版授权能迁移

## R5 打包发布

- [ ] macOS arm64 DMG、Windows x64 NSIS 安装包
- [ ] 产物自检全绿(`verify-package.cjs`)
- [ ] 文档、测试脚本、实验产物**不进安装包**
